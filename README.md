## 💻 Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/codewsakp/portfolio.git
```

**2. Navigate to the project directory**

```bash
cd portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```
Open the local URL displayed in your terminal.
later you can deploy your created portfolio on vercel as well.

## 📁 Customisation

The portfolio uses a modular structure to make future updates easier.

- `src/data/` – Update profile information, projects, skills, education, achievements and certifications.
- `public/images/` – Replace profile and project images.
- `public/files/` – Update your resume.
- `src/components/` – Modify reusable UI components and layouts.

Refer to the source code and comments for further customisation.
